# 원칙

- native first: 새 앱을 만들기 전에 Galaxy 기본 기능과 Samsung 공식 도구를 확인합니다.
- least privilege: 가능한 가장 좁은 권한과 API를 사용합니다.
- reversible: 모든 설정과 설치에는 원상복구 방법을 제공합니다.
- evidence before imitation: 기억이나 추측만으로 iOS 동작을 복제하지 않고 실제 장면을 확인합니다.
- honest compatibility: 한 기기에서의 성공을 전체 Galaxy 지원으로 확대하지 않습니다.
- no hidden telemetry: 앱은 명시하지 않은 분석과 네트워크 전송을 하지 않습니다.
