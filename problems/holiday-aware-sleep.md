# 한국 공휴일을 주말처럼 취급하는 수면 자동화

## 1. 원하는 사용자 시나리오

매일 22:00에 수면 모드가 자동으로 시작한다. 평일에는 07:00, 토·일에는 정오에 끝난다. 평일과
겹치는 한국 법정공휴일도 주말처럼 정오까지 이어진다. 알람은 울리고, 같은 발신자가 15분 안에
다시 전화하면 벨소리를 허용한다. 수면 모드가 통화를 끊거나 상대방에게 마이크 소리를 막아서는 안
된다.

## 2. Galaxy 기본 기능의 경계

Samsung 수면 모드로 평일·주말 시간과 방해 금지 예외는 구성할 수 있다. 하지만 “오늘이 동기화된
한국 법정공휴일이면 평일 종료 시간을 정오로 바꾼다”는 조건은 기본 루틴에서 직접 만들 수 없었다.
캘린더 제목을 수동으로 관리하거나 광고 기반 자동화 앱을 계속 쓰는 것은 자동 수면의 목적과 맞지
않았다.

## 3. 선택한 조합

기본 수면 일정은 Samsung 모드가 담당하고, [`apps/holiday-sleep`](../apps/holiday-sleep/)은 평일
공휴일 07:00:15부터 12:00까지만 별도의 방해 금지 규칙을 이어받는다. 15초 지연은 07:00에 끝나는
기본 모드와의 상태 전환 경계를 피하기 위한 것이다. 토·일은 기본 일정이 이미 정오까지이므로 앱이
개입하지 않는다.

공휴일은 인터넷에서 임의로 내려받지 않는다. 휴대폰에 동기화된 Samsung 공식 공휴일 캘린더를
우선하고, 대한민국 Google 휴일 캘린더를 제한된 제목 목록으로 fallback한다. 설날·추석 연휴의
Samsung all-day 표현도 함께 처리한다.

## 4. 권한과 안전 경계

| 권한 | 이유 | 하지 않는 일 |
|---|---|---|
| 캘린더 읽기 | 한국 공휴일 달력과 해당 날짜 판별 | 일정을 서버로 전송하지 않음 |
| 방해 금지 정책 | 앱 전용 자동 규칙 생성·상태 변경 | 통화 차단·마이크·Bluetooth 변경 안 함 |
| 정확한 알람 | 07:00:15와 12:00 경계 실행 | 사용자 알람을 수정하지 않음 |
| 부팅 수신 | 재부팅 뒤 다음 실행 예약 | 백그라운드 네트워크 없음 |

앱의 정책은 알람·미디어와 반복 발신자를 허용하고 일반 전화·메시지 알림은 무음으로 둔다. 방해
금지는 전화 연결 자체를 끊지 않으며 통화 중 마이크 경로도 바꾸지 않는다. 단, 기종·통신사 앱의
표시 방식은 별도 확인이 필요하다.

## 5. 설치와 원상복구

기본 수면 일정은 [수면 레시피](../recipes/sleep-schedule.md)를 먼저 구성한다. 앱을 열어 캘린더,
방해 금지 정책, 정확한 알람 권한을 차례로 허용하고 `자동 연장 사용`을 켠다. 상태 카드가 인식한
달력과 다음 시작·종료를 표시한다.

되돌릴 때는 앱의 자동 연장을 먼저 끄고 설정의 방해 금지 자동 규칙에서 `공휴일 수면 연장`이
비활성인지 확인한다. 그 뒤 앱을 삭제하고 필요하면 캘린더·정확한 알람 권한을 철회한다. 기본 Samsung
수면 일정은 그대로 남는다.

## 6. 검증 범위와 미확정

Galaxy Z Fold8 `SM-F971N`, Android 17, One UI 9.0, 한국어·대한민국 공휴일 캘린더에서 직접
검증했다. 다른 국가, 다른 캘린더 공급자와 One UI의 방해 금지 정책 병합 방식은 미검증이다. 향후
임시공휴일이 달력에 늦게 동기화될 때의 동작도 실제 날짜별 결과 행으로 계속 기록해야 한다.
