# 집·외출·배터리 상태에 맞춰 자동으로 바꾸기

집에 도착하면 믿을 수 있는 집 Wi-Fi를 사용하고, 밖에서는 모르는 Wi-Fi에 저절로 연결되는 일을
줄이고 싶었습니다. 배터리가 부족할 때는 절전 기능을 켜고, 충전되면 평소 설정으로 돌아오게
했습니다. 회의 모드는 필요할 때 직접 누르지만 이 세 가지는 조건에 따라 자동으로 시작하고
끝납니다.

별도의 앱은 만들지 않았습니다. Samsung 모드·루틴만으로 시작 조건과 종료 뒤 복원을 함께
설정했습니다. 위치를 조건으로 쓰면 Android의 위치 권한과 백그라운드 확인에 영향을 받고,
Wi-Fi 조건은 해당 네트워크가 보이는 곳에서만 작동합니다.

공개 문서에는 실제 집과 회사 주소, 지도 좌표와 Wi-Fi 이름을 넣지 않습니다. 레시피의
‘내 집’과 ‘신뢰하는 Wi-Fi’는 각자 자신의 기기에서 골라야 합니다. 화면을 공유할 때에도
지도와 주변 장소, Wi-Fi 이름과 계정이 보이지 않는지 확인해야 합니다.

배터리 기준값과 세부 동작은 현재 기기에서 설정을 다시 확인하기 전까지 확정하지 않았습니다.
자동화를 멈추려면 각 루틴을 하나씩 끄면 됩니다. Wi-Fi와 절전 기능이 루틴 종료 뒤 실제로 원래
상태로 돌아오는지도 항목별로 시험해야 합니다.
