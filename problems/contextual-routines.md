# 집·외출·배터리 상태를 자동화하기

## 사용자 시나리오

집에 도착하면 신뢰하는 집 네트워크를 쓰고, 외출하면 임의의 Wi-Fi에 자동으로 붙는 상황을 줄인다.
배터리가 낮을 때는 절전 설정을 자동 적용하고 충전되면 정상 상태로 돌아간다. 회의 모드만 직접
누르고 이 세 루틴은 조건으로 자동 시작·종료한다.

## 선택한 수준

Samsung 모드·루틴만으로 조건과 되돌리기를 한 쌍으로 구성한다. 별도 앱이나 지속적인 위치 서버는
필요하지 않다. 단, 위치 조건은 Android 위치 권한과 백그라운드 판정에 의존하고 Wi-Fi 조건은
네트워크가 보이는 범위에서만 동작한다.

## 개인정보 경계

공개 저장소에는 실제 집·회사 주소, 좌표, SSID를 넣지 않는다. 레시피의 `<내 집>`과 `<신뢰 Wi-Fi>`
를 각 사용자가 자기 기기에서 선택한다. screenshot을 올릴 때 지도, 주변 장소, Wi-Fi 이름과 계정
정보를 가린다.

## 미확정과 원상복구

배터리 임계값과 오른쪽 화면별 세부 action은 현재 기기 export를 다시 확인하기 전까지 임의로
고정하지 않는다. 각 루틴을 하나씩 끄면 자동 변경이 멈추며, 루틴의 `종료 시 원래 상태로 복원`
동작이 실제로 실행되는지 Wi-Fi·절전 항목마다 별도 시험한다.
