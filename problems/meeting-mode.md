# 회의를 한 번 눌러 준비하기

## 사용자 시나리오

회의 직전에 여러 설정을 찾지 않고 `회의` 한 번만 선택한다. Bluetooth 이어폰·헤드폰이 녹음 입력을
바꾸는 상황을 피하기 위해 Bluetooth를 끄고 음성 녹음 앱을 연다. 회의 중 전화 동작은 사용자가
선택한 무음 또는 차단 정책을 따른다. 회의가 끝나면 원래 통신·알림 상태로 돌아간다.

## 선택한 수준

이 문제는 별도 앱보다 Samsung 모드·루틴으로 먼저 해결한다. 현재 구성은 사용자가 직접 시작하는
회의 모드이고, 수면·귀가·외출·배터리 루틴과 달리 자동 조건을 두지 않는다. 앱을 여는 것과 녹음을
실제로 시작하는 것은 같은 권한이 아니다. One UI가 녹음 시작 action을 공식 제공하지 않으면 화면
좌표 자동 탭이나 광범위한 접근성 권한을 추가하지 않는다.

## 안전과 되돌리기

Bluetooth를 끄면 AirPods뿐 아니라 연결된 키보드·마우스·차량 등도 모두 끊어진다. 전화 `차단`은
단순 무음보다 상대방 경험에 더 큰 영향을 주므로 레시피 적용 전에 실제 수신 시험을 해야 한다.
회의 종료 시 Bluetooth와 전화 정책을 원복하도록 종료 동작을 짝으로 둔다.

정확한 메뉴와 현재 설정 export를 개인정보 없는 형태로 다시 캡처하기 전까지는
[회의 레시피](../recipes/meeting-mode.md)를 `단일 기기 구성 기록`으로만 제공하며 보편 권장값으로
표시하지 않는다.
