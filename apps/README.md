# 직접 만든 앱

Galaxy 설정과 Samsung 공식 도구, 이미 공개된 앱으로 원하는 동작을 만들 수 없었던 세 가지 문제는
작은 Android 앱으로 해결했습니다.

- [맨 위로 톡](tap-to-top/): 상태 표시줄을 누르면 현재 화면을 위로 한 번 움직입니다.
- [공휴일 수면 연장](holiday-sleep/): 평일 법정공휴일에는 방해 금지를 정오까지 이어 줍니다.
- [에어팟 한눈에](airpods-glance/): 연결된 AirPods의 배터리와 큰 연결 화면을 보여줍니다.

앱마다 빌드 방법과 필요한 권한, 저장하는 정보, 확인한 기기와 삭제 방법을 따로 적었습니다.
여기에 있다고 해서 범용 배포가 끝났다는 뜻은 아닙니다. 세 앱 모두 현재 Galaxy Z Fold8 한 대를
중심으로 시험했습니다.

세 앱 모두 APK를 만들어 실기기에 설치했습니다. 현재는 소스를 공개한 상태이며 다운로드용 APK는
아직 첨부하지 않았습니다. 각 build.sh를 실행하면 테스트용 키로 서명된 설치 가능한 APK가 생성됩니다.

맨 위로 톡과 공휴일 수면 연장의 화면은 권한과 동작을 설정하는 데 사용합니다. 평소에는 다른 앱의
스크롤을 돕거나 정해진 시간에 실행되는 사용성 보완 도구입니다. 에어팟 한눈에는 배터리 화면·위젯·
연결 카드처럼 직접 보는 화면도 제공합니다.
