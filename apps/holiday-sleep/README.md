# 공휴일 수면 연장

휴대폰에 동기화된 삼성 및 Google 한국 공휴일 달력을 읽어, 평일 법정공휴일 오전 7시 00분 15초부터 정오까지 전용 방해 금지 규칙을 활성화하는 로컬 Android 앱입니다.

- 인터넷 권한 없음
- 알람 허용
- 같은 번호가 15분 안에 다시 전화하면 벨소리 허용
- 통화, 마이크, 블루투스 설정은 변경하지 않음
- 부팅, 시간 변경, 시간대 변경 후 자동 재예약

## 검증 환경

- Samsung Galaxy Z Fold8 (`SM-F971N`)
- Android 17
- One UI 9.0

다른 기기와 One UI 버전에서는 캘린더 제공자와 방해 금지 규칙 동작이 다를 수 있습니다.

`./build.sh`로 APK를 빌드할 수 있습니다.

Android SDK Platform 36, Build Tools 36.0.0과 JDK가 필요합니다. SDK가 기본 위치에 없다면
`ANDROID_SDK_ROOT`를 지정합니다. 생성되는 `build/holiday-sleep.apk`는 각 개발자의 `.local/`
debug key로 서명되며 공개 배포용 APK가 아닙니다.

## 권한과 원상복구

- 캘린더 읽기: 로컬 한국 공휴일 판별
- 방해 금지 정책: `공휴일 수면 연장` 자동 규칙 상태 변경
- 정확한 알람·부팅 수신: 매일 경계와 재부팅 뒤 재예약

앱을 열어 `자동 연장 사용`을 끄고 방해 금지 자동 규칙이 비활성인지 확인한 뒤 삭제합니다. 기본
Samsung 수면 모드는 별개라서 삭제되지 않습니다. 상세 흐름은
[문제 문서](../../problems/holiday-aware-sleep.md)에 있습니다.
