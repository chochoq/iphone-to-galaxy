# 공휴일 수면 연장 개발 안내

[사용법](../README.md) · [Samsung 모드와 함께 설정하기](../../../recipes/holiday-extension.md)

이 앱은 Samsung 수면 모드의 시간을 바꾸거나 기상 알람을 늦추지 않습니다.
평일 공휴일의 지정 구간에 앱 전용 방해 금지 규칙을 켭니다. 일반 수면 일정과 시계 알람은 별개입니다.

## 구조와 불변 조건

소스는 [`src/com/chocho/holidaysleep/`](../src/com/chocho/holidaysleep/)에 있습니다.

- 시간 계산: `ScheduleWindow`. 같은 날의 시작 이상·종료 미만 구간이며 평일 공휴일에만 활성화합니다.
- 설정 저장: `ScheduleSettings`. 시작·종료를 함께 저장하고, 시간 저장만으로 꺼진 자동 연장을 켜지 않습니다.
- 공휴일 확인: `HolidayCalendar`. 동기화된 공휴일 캘린더를 우선순위에 따라 읽습니다. 임의의 개인 일정을 공휴일로 보지 않습니다.
- 예약: `Scheduler`, `HolidayAlarmReceiver`, `SystemEventReceiver`. 재부팅·시각·시간대 변경 뒤 예약을 다시 계산합니다.
- 방해 금지: `ZenController`, `HolidayConditionProvider`. 앱 전용 규칙만 관리하며 Samsung 수면 모드나 통화·Bluetooth 설정은 변경하지 않습니다.

기본 구간은 07:00:15–12:00입니다. 15초는 Samsung 수면 모드 종료와 바로 겹치는 변경을 피하려고
선택한 간격이며, 모든 기기에서 충돌을 막는 보장은 아닙니다. 사용자가 바꿀 수 있고 Samsung 모드와 자동 동기화하지 않습니다.
시·분만 편집하면 원래 초를 보존합니다. 시작과 종료가 같거나 자정을 넘는 입력은 거부합니다.

캘린더는 Samsung 공휴일 소스를 우선하고 없으면 대한민국 휴일 소스를 찾습니다.
대체 소스의 제목은 법정공휴일 목록과 대조하며, Samsung의 설·추석 중심일과 앞뒤 날짜 처리는
`HolidayCalendar`에 따로 있습니다. 권한이 없거나 해당 캘린더가 없으면 공휴일이라고 추정하지 않습니다.
앱은 공휴일을 인터넷에서 내려받지 않으므로 기기의 캘린더 동기화 상태에 의존합니다.

전용 규칙은 알람과 15분 안의 반복 전화를 허용합니다. 다른 방해 금지 규칙이 동시에 켜져 있을 때의
최종 정책은 OS가 합칩니다. 앱 규칙에 예외가 있다고 모든 조합에서 알람·벨소리를 보장하지 않습니다.

## 검사하기

저장소 루트에서 실행합니다. [공통 빌드 준비](../../../docs/GETTING-STARTED.md)가 필요합니다.

```sh
sh shared/android-ui/test-core.sh
sh apps/holiday-sleep/test-core.sh
sh apps/holiday-sleep/build.sh
```

시간 모델에서는 경계 초, 잘못된 저장값, 평일·주말·공휴일 조합을 검사합니다.
실제 기기에서는 공휴일 소스 인식 → 예약 → 규칙 활성화·해제와 알람·반복 전화 예외를 따로 확인해야 합니다.
자동 검사 횟수가 실제 공휴일을 기다려 실행한 횟수는 아닙니다.

Android 15 이상이 필요합니다. 사용하는 `AutomaticZenRule.Builder`는 API 35부터 제공되므로
설치 조건만 낮추면 이전 OS에서 안전하게 실행할 수 없습니다.
[확인한 기기와 남은 시험](../../../compatibility/README.md)을 참고하세요.

## 변경 순서

시간·캘린더 판단 규칙과 반례를 먼저 검사하고, 저장·예약·방해 금지 연동을 연결한 뒤 화면을 수정합니다.
취소 시 기존 시간이 남는지, 저장 실패를 성공으로 표시하지 않는지, 꺼진 기능이 켜지지 않는지 확인합니다.
삭제 시험 전에는 자동 연장을 끄고 앱 전용 규칙이 비활성화됐는지 확인합니다.
