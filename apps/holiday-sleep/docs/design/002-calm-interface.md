# D2. 시간부터 읽히는 수면 연장 화면

> 2026-09-08 개발 당시의 기록입니다. 아래 ‘공개본 미반영’ 표시는 당시 상태를 뜻합니다.
> 이번 선별 소스에는 포함되지만 원본 기기 자료는 공개하지 않습니다.

## D2.1 근거와 변경 범위

사용자와 합의: 밝은 회색 바탕, 흰색 둥근 카드, 보라색 강조. 작은 달 아이콘과 짧은 소개,
나란한 시작·종료 시간, 자동 연장 카드, 접힌 상세 상태, 변경 시에만 저장·취소 표시.
원형 시계와 과한 그림자·유리 효과는 넣지 않는다. D1의 시간·예약 동작은 유지한다.

확인한 참고 자료:

- https://support.apple.com/ko-kr/guide/iphone/iphaf56dceb4/ios
  실제 수면 일정 이미지의 큰 시간 숫자, 구획과 여백을 참고했다.
- https://developer.apple.com/design/resources/
  공식 UI Kit 미리보기의 둥근 설정 그룹과 강조 위계를 참고했다.
- 사용자가 보낸 Figma 검색 페이지와 연결된 Figma 파일은 HTTP 403이어서 내부를 확인하지 못했다.

Apple 이미지·서체·아이콘을 앱에 복사하지 않는다. Android 시스템 글꼴과 직접 그린 달,
기본 접근성 동작을 사용한다. 참고 이미지와 공개용 앱 자산을 혼동하지 않는다.

## D2.2 시나리오와 권장 동작

| ID | 시나리오 | 기준 |
|---|---|---|
| V1 | 평소 앱 열기 | 첫 화면에서 저장된 시작·종료와 자동 연장 상태를 읽는다. 기술 설명은 접는다. |
| V2 | 시간 수정 | 시간을 누르면 선택 창. 변경 안내와 저장·취소가 그때만 나타난다. |
| V3 | 권한 또는 달력 부족 | 상세를 접어도 문제 안내는 보인다. 자동화가 준비됐다고 거짓 표시하지 않는다. |
| V4 | 상세 확인 | 실행 예정·공휴일 달력·권한·기능 한계를 펼쳐 확인하고 다시 접는다. |
| V5 | 좁은 화면·큰 글씨 | 시간이 잘리지 않도록 크기/배치를 조정한다. 화면 전체 스크롤을 유지한다. |
| V6 | 열린 Fold/태블릿 | 콘텐츠 최대 폭을 제한해 시간과 스위치가 양 끝으로 벌어지지 않는다. |
| V7 | 초기 설치/정상 상태/수정 상태 | 각각의 미리보기를 구분한다. 예시 데이터 화면은 실제 권한 상태로 주장하지 않는다. |

## D2.3 구현 순서와 판단

스타일 helper(색, 라운드 배경, 간격) → 레이아웃 구획 → 상태·오류 표시 → 회귀 검사 →
격리된 테스트 에뮬레이터 화면 확인 순서로 작업한다. 사용자 폰에는 새 APK를 설치하지 않는다.
에뮬레이터를 사용할 수 없으면 그림을 실제 앱 실행 화면으로 꾸미지 않고 한계를 알린다.

내 판단: 기본 화면에 모든 설명을 펼친 것이 기존 화면을 무겁게 만들었다. 장식 추가보다
시간, 자동 연장, 필요할 때 보는 설명의 우선순위를 나누는 것이 먼저다. ‘기상’ 대신
‘시작/종료’를 사용해 이 앱이 알람을 만드는 것처럼 보이지 않게 한다.

## D2.4 검증

1차: V1–V7과 합의한 위계 검토. 2차: D1 자동 테스트와 APK 빌드로 동작 회귀 확인.
3차: 에뮬레이터 기본·수정·잘못된 시간·넓은 화면 확인. 실제 폰 설치는 후속 승인 전 보류.
상세 상태 접기와 미저장 선택은 회전 시 유지한다. 부족한 권한 안내는 접기와 독립시킨다.

## D2.5 구현 중 발견과 설계 반영

기존 시작 시각은 07:00:15다. 큰 숫자에는 분까지만 표시하되 아래에 ‘15초부터 시작’을 붙이고,
접근성 설명에는 초까지 읽도록 했다. 초가 0인 종료 쪽도 작은 설명의 공간은 유지해 두 열을 정렬했다.
좁은 화면(340dp 미만) 또는 큰 글씨(배율 1.25 초과)는 두 시간을 세로로 놓는다.
넓은 화면은 콘텐츠 폭을 560dp로 제한한다. 부족한 권한이나 달력은 접힌 상세 밖에도 안내한다.

기존 AVD는 시스템 이미지 일부가 없어 시작하지 못했다. 기존 환경을 고치지 않고 별도 임시
Android 15 ATD 이미지를 받아 검사했다. ATD는 기본 화면 그리기가 꺼져 있어 테스트 기기에서만
활성화했다. 실제 Fold8·One UI 9.0의 시스템 바와 시간 선택 창은 이 미리보기로 검증되지 않는다.

## D2.6 사용자 피드백: iOS 색과 구성, 실기기에서 보기

사용자는 보라색 위주의 시안을 원하지 않았고 iOS 레퍼런스를 다시 확인하라고 요청했다.
이미지 링크나 맥 미리보기 대신 갤럭시에 설치해 직접 볼 수 있게 한다. 이번 요청으로 실기기
설치 보류 조건은 해제됐다. 커밋·공개본 반영·배포는 계속 금지다.

Apple의 iOS 26 수면 시간 지정 공식 화면을 다시 확인했다. 시간 숫자는 검정이고 ‘추가’ 같은
조작은 파랑이며 보라는 작은 수면 아이콘에 제한되어 있었다. 기존 큰 보라색 숫자 버튼과 달 장식은
그 참고 화면에서 가져온 것이 아니라 내 해석이었다. 이 해석을 철회한다.

기준: 배경 #F2F2F7, 흰색 설정 그룹, 검정 시간, 파랑 조작, 초록 켜짐 스위치.
이 색상 코드는 구현용으로 선택한 iOS 계열 팔레트이며 공식 스크린샷 픽셀 실측값이라고 주장하지 않는다.
그룹 모서리·패딩을 줄이고 장식용 달과 큰 보라색 시간 배경을 제거한다. 구분선과 작은 섹션 제목으로
내용을 나눈다. 별도 iOS 서체·이미지를 배포하지 않고 네이티브 Android 글꼴과 접근성을 유지한다.

수정 후 예상: 같은 첫 화면에서 더 적은 장식으로 시간·자동 연장·상세 조작을 읽을 수 있다.
재검사: 기존 핵심 테스트 → 서명 호환성 → 설정을 유지한 업데이트 설치 → 실제 화면과 시간 선택 창
확인 → 기존 시간을 바꾸지 않고 편집 취소 검사 → 앱 첫 화면을 사용자에게 열어두기.

추가로 확인한 공식 설명: https://support.apple.com/ko-kr/guide/iphone/iph304a683a0/26/ios/26
Figma 파일 내부는 이번에도 확인했다고 주장하지 않는다.

## D2.7 앱 아이콘

사용자가 앱 커버도 그려달라고 요청했다. 앱 목록에서 찾는 launcher icon으로 해석했다.
작은 크기에서 수면 앱임을 알아보는 시나리오를 기준으로, 글자 없이 파란 바탕·흰 초승달·별을 사용한다.
이미지 생성 후 가장자리 투명도를 검사하고 배경만 불투명하게 다시 생성했다.
Android adaptive icon과 테마용 단색 아이콘을 연결한다. 빌드·업데이트 후 실제 One UI 앱 목록에서
기본 아이콘이 교체되고 달·별이 식별되는지 확인한다. 폰의 기존 홈 배치와 아이콘 테마 설정은 바꾸지 않는다.
