## 미리보기 근거

별도로 만든 AOSP ATD Android 15(API 35), arm64 에뮬레이터를 사용했다.
실제 갤럭시의 캘린더·개인 데이터는 가져오지 않았다. 준비된 상태를 보기 위해 에뮬레이터에만
캘린더 읽기·방해 금지·정확한 알람 권한을 허용하고 공휴일 표시의 빈 테스트 달력을 넣었다.
따라서 ‘오늘은 공휴일이 아니에요’는 이 테스트 데이터에서 나온 표시다. 실제 공휴일 동기화나
Fold8의 실제 준비 상태를 증명하는 화면이 아니다. 캡처는 앱 실행 화면이며 합성 이미지가 아니다.

원본 파일은 private room의 `artifacts/holiday-style-preview.T8KskR/`에 있다.

- `01-permissions-needed.png`: 권한 부족
- `02-ready.png`: 정상 기본 화면, 기본값 07:00:15–12:00
- `03-unsaved.png`: 종료 10:00 미저장 선택
- `04-narrow-large-text.png`: 좁은 폭·큰 글씨
- `05-wide.png`: 넓은 화면
- `06-invalid.png`: 잘못된 시간

## 피드백과 남은 검사

시간의 초까지 큰 글씨로 넣는 대신 15초를 별도 설명에 남겼다. 상세를 접어 화면 길이는 줄이되
권한 경고는 숨기지 않았다. 좁은 화면에서 가로 배치를 고집하지 않아 숫자가 잘리는 것을 피했다.

실제 One UI 9.0/Android 17의 시스템 바·시간 선택 창, Fold 접기·펼치기, TalkBack 낭독,
회전 중 미저장 선택 보존, 공휴일 경계에서 실제 방해 금지·전화·알람 동작은 아직 이번 UI 빌드로
시험하지 않았다. 먼저 미리보기를 사용자에게 보여주고, 설치를 요청받으면 실기기 확인으로 이어간다.

## 1.2.1-dev 실기기 추가 검사

사용자는 보라색 시안을 거절하고 iOS 레퍼런스 재확인과 직접 폰 설치를 요청했다.
공통 색·구획·시간 표시를 수정했다. 버전은 code 3 / 1.2.1-dev로 구분했다.
공개 레포는 건드리지 않았으며 커밋·푸시·배포하지 않았다.

- 순수 모델 2,419,550 / 저장 대역 10 / 예약 대역 18 assertion 재통과.
- 1.1 백업과 새 APK 서명 인증서 일치, APK v2/v3 검증 통과.
- Fold8 / Android 17 / One UI 9.0에서 업데이트 설치 성공.
- 업데이트 전후 07:00:15–12:00, 자동 연장 켜짐과 세 권한 허용 유지.
- 실제 시스템 바와 앱 콘텐츠 겹침 없음, 첫 화면과 상세 정보 읽기 확인.
- 시간 숫자를 누르면 시간 선택 창이 열리는 것 확인. 취소 후 기존 값 유지 확인.
- One UI에서 기본 Switch drawable 교체만으로 손잡이가 잘리는 문제 발견.
  네이티브 Switch의 입력 의미를 유지한 자체 렌더링으로 수정하고 실기기 재확인.

실제 공휴일 도래, 전화·알람 소리, 접기·펼치기, TalkBack 전체 사용, 스위치 드래그의 세부 동작은
이번 확인 범위가 아니다. 스위치 상태 자체는 사용자의 켜짐 설정을 그대로 유지했다.
private artifacts의 07/08 실기기 캡처는 내부 확인용이며 공개용으로 선별·비식별 처리하지 않았다.
