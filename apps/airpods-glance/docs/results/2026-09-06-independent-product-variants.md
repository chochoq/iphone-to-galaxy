# 독립 회전 적용과 케이스 변형 미리보기

> **2026-09-07 폐기 정정:** 이 문서의 독립 회전 적용은 테스트에는 성공했지만 제품 판단은
> 잘못됐다. 사용자의 iOS 실기기 재확인과 전날 영상 원본 모두 케이스를 열었을 때 두 이어버드가
> 한 쌍으로 함께 회전하고 닫힌 케이스를 따로 표시함을 보여 준다. 앱은 기존 공동 pair 자산으로
> 복원했고 닫힌 케이스 자산으로 교체했다. 아래 내용은 실패 과정과 기술 검증 이력이다.

## 미검증과 범위

사용자 부재 중 폰 화면을 강제로 깨우거나 팝업을 띄우지 않았다. 따라서 새 animation의
휴대폰 재생을 눈으로 확인한 상태는 아니다. 배터리/연결/케이스 자동 선택은 변경하지 않았다.
빈 케이스 정면에서는 카메라 각도상 내부 홈이 보이지 않는다. 내부 모델의 완전성은 미확정이다.
한쪽 수납 자산은 시각 A/B이며 물리 좌우나 AAP slot에 아직 연결하지 않았다.
케이스 네 변형은 cardinal 미리보기 단계로, 운영 animation·자동 상태 전환 완료가 아니다.
