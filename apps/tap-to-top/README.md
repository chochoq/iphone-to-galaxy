# 맨 위로 톡

<img src="res/drawable-nodpi/ic_launcher_folded_v3.png" width="64" height="64" alt="맨 위로 톡 아이콘">

**[APK 다운로드](https://github.com/chochoq/iphone-to-galaxy/releases/download/v0.0.5/tap-to-top-0.0.5.apk)** · [설치 안내](../../docs/INSTALL.md)

Android 12 이상 · 접근성 권한 필요 · 루팅·USB 불필요

아이폰에서 하던 것처럼 화면 위쪽의 상태 표시줄을 누르면 보고 있던 화면이 위로 올라갑니다.
상태 표시줄을 아래로 끌면 원래대로 알림창이 열립니다.

0.0.5부터 지원하는 목록에는 **‘맨 위’라는 목적지**를 요청합니다. 앱을 하나씩 등록하는 방식은
아니며, 화면이 제공하는 기능과 목록 방향을 확인합니다. 지원하지 않는 화면은 기존처럼 한 번만
쓸어 올리므로 아주 긴 피드에서는 중간에 멈출 수 있습니다.

Fold8에서 인스타·YouTube 홈의 맨 위 도착과 이동 중 화면을 끌어 멈추기를 확인했습니다.
X 추천·팔로우 중 홈에는 별도의 상단 이동 보완이 있습니다. 다만 X 자체 이동이 시작된 뒤
원하는 중간 지점에서 멈추기는 확인하지 못했으며, 홈 재선택 때 새 글이 반영될 가능성도 있습니다.
동작이 맞지 않으면 ‘앱의 맨 위 이동 사용’을 끄고 기존 방식으로 돌아갈 수 있습니다.

반복 스와이프와 숨은 홈 버튼의 좌표 클릭은 사용하지 않습니다.
이동 속도·애니메이션은 대상 앱이 정하므로 모든 화면을 iPhone과 똑같이 바꾸지는 않습니다.

왜 이 방법을 선택했는지와 실패한 방법은 [개발 안내](docs/DEVELOPMENT.md)에 기록했습니다.

## 앱에서 조절하기

- 한 번 탭 또는 두 번 탭으로 실행하기
- ‘앱의 맨 위 이동 사용’ 켜기·끄기 (처음에는 켜져 있음)
- 스크롤 세기 60–160%, 제스처 길이 40–75% 조절하기
- 접근성 권한은 유지하고 기능만 잠시 끄기
- 확인 후 조절값만 기본값으로 되돌리기

기본값은 한 번 탭·세기 100%·길이 62%입니다. 길이는 스와이프 입력의 범위이지, 목록이 실제로
움직일 거리가 아닙니다. 값을 높여도 아주 긴 피드의 처음까지 한 번에 도착한다고 보장하지 않습니다.
숫자는 저장해야 적용되며 취소하면 이전 값을 유지합니다.

세기와 길이는 기존 한 번 쓸어 올리기에만 적용합니다. 앱 자체의 목적지 이동 속도는 바꾸지 않습니다.
설정 화면의 마지막 시도 안내는 요청 경로를 알려 주며, 실제 상단 도착을 자동 판정한 결과가 아닙니다.

처음에는 ‘사용법 및 권한’에서 접근성 설정을 열어 ‘맨 위로 톡’을 켭니다.
한 번·두 번 탭은 누르는 즉시 적용됩니다. 숫자 편집은 ‘저장’을 눌러야 적용됩니다.

## 확인한 환경

- Samsung Galaxy Z Fold8 (SM-F971N)
- Android 17
- One UI 9.0

다른 기기와 화면 비율, One UI에서는 터치 영역과 이동 거리가 달라질 수 있습니다.

- 인스타 446.0.0.49.77·YouTube 21.37.42 홈: 상단 도착과 중간 개입 확인
- X 12.25.2-prod.01 추천·팔로우 중 홈: 상단 도착 확인, 자체 이동 도중 가로채기는 미확인
- 웹·그리드·행 정보가 부족한 화면: 공통 상단 이동을 보장하지 않음

앱의 프로필·댓글·검색·메시지까지 모두 확인한 것은 아닙니다. [자세한 호환성](../../compatibility/)

## 접근성 권한과 개인정보

화면에서 스크롤할 수 있는 영역을 찾고 위쪽 움직임을 보내기 위해 접근성 서비스를 사용합니다.
이 권한은 다른 앱의 화면 구조를 볼 수 있으므로 소스를 검토하고 신뢰할 수 있을 때만 켜야 합니다.

인터넷, 사진, 마이크와 위치 권한은 요청하지 않습니다. 화면 내용이나 사용 기록도 저장하거나
전송하지 않습니다.

## 빌드

이 앱 폴더에서 실행합니다. [공통 빌드 준비](../../docs/GETTING-STARTED.md)가 필요합니다.

~~~sh
sh test-core.sh
./build.sh
~~~

APK는 build/tap-to-top.apk에 생성됩니다. Android SDK Platform 36, Build Tools 36.0.0과 JDK가
필요합니다. SDK가 기본 위치에 없다면 ANDROID_SDK_ROOT를 지정합니다. 직접 빌드한 APK는 개발자의
테스트용 키로 서명됩니다. 공식 APK는
[GitHub Releases](https://github.com/chochoq/iphone-to-galaxy/releases/tag/v0.0.5)에서 받습니다.
[폰에서 설치하기](../../docs/INSTALL.md) · [배포용 서명과 업데이트](../../docs/RELEASING.md)

되돌리려면 설정의 접근성 설치 앱에서 ‘맨 위로 톡’을 끄고 앱을 삭제합니다. 권한과 앱별 한계는
[문제 문서](../../problems/tap-status-bar-to-scroll-top.md)에서 확인할 수 있습니다.
