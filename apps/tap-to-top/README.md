# 맨 위로 톡

화면 상단 상태 표시줄을 한 번 탭해 현재 화면을 한 번의 자연스러운 관성으로
위쪽으로 빠르게 이동하는 개인용 안드로이드 앱입니다. 상태 표시줄을 아래로 쓸면
기존처럼 알림창이 열립니다.

스크롤은 여러 동작을 이어 붙이지 않고 한 번의 관성 동작으로 실행됩니다.
이동 중 화면을 다시 만지면 안드로이드의 일반 스크롤처럼 바로 가로챌 수 있습니다.
X에는 조금 더 강한 단일 플릭을 사용하지만, Android는 다른 앱에 공통으로 쓸 수
있는 절대 맨 위 API를 제공하지 않습니다. 따라서 아주 긴 X 피드는 한 번에 완전한
처음까지 가지 않을 수 있습니다. 이를 보완하려고 반복 플릭을 예약하면 재가속과
입력 탈취가 생기므로 사용하지 않습니다.

설계 근거와 실패 이력은 [설계 인덱스](docs/design/INDEX.md)에서 확인할 수 있습니다.

## 검증 환경

- Samsung Galaxy Z Fold8 (`SM-F971N`)
- Android 17
- One UI 9.0

이 환경에서 직접 검증했으며, 다른 기기·화면 비율·One UI 버전에서는 동작이나 레이아웃이
다를 수 있습니다.

## 개인정보 보호

- 인터넷, 사진, 마이크, 위치 권한을 요청하지 않습니다.
- 접근성 서비스는 스크롤 가능한 화면을 찾고 스크롤 동작을 실행하는 데만 사용합니다.
- 화면 내용과 사용 기록을 저장하거나 전송하지 않습니다.

## 빌드

```sh
chmod +x build.sh
./build.sh
```

완성 APK는 `build/tap-to-top.apk`에 생성됩니다.

Android SDK Platform 36, Build Tools 36.0.0과 JDK가 필요합니다. SDK가 기본 위치에 없다면
`ANDROID_SDK_ROOT`를 지정합니다. APK는 `.local/`의 개발자별 debug key로 서명되며 공개 배포용
서명이 아닙니다.

되돌릴 때는 설정의 접근성 설치 앱에서 `맨 위로 톡`을 끈 뒤 앱을 삭제합니다. 상세 권한·한계와
앱별 반례는 [문제 문서](../../problems/tap-status-bar-to-scroll-top.md)에 있습니다.
