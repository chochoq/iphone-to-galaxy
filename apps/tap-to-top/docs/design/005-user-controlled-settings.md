# D-005 — 내 손에 맞추는 맨 위로 톡

> 2026-09-08 개발 당시의 기록입니다. 아래 ‘공개본 미반영’ 표시는 당시 상태를 뜻합니다.
> 이번 선별 소스에는 포함되지만 원본 기기 자료는 공개하지 않습니다.

## Why / What

고정된 제스처만 제공하는 도구에서 익숙한 iOS 계열 설정 화면과 직접 조절 가능한 앱으로 바꾼다.
아이콘은 그대로 둔다. 앱 내부 조절값 변경에 재빌드가 필요하지 않도록 한다.

후속 요청(2026-09-08): 사용자가 앱 아이콘 제작도 요청해 별도로 추가했다.
[아이콘 설계·프롬프트·검증](../../assets/icon/README.md). 이전 제외 범위는 당시 결정으로 보존한다.

## 근거와 한계

Apple scrollsToTop 공식 API를 2026-09-08 다시 읽었다. iOS는 상태 표시줄 탭을 해당 앱 내부
UIScrollView에 전달한다. Android 외부 앱을 움직이는 합성 플릭과 동일하지 않으며 전체 피드의
절대 상단이나 동일 속도를 보장할 수 없다. D-001의 반복 플릭 금지·사용자 개입 우선은 유지한다.
설정 화면은 실제 Apple iOS 26 설정 그룹의 검정/회색 정보·파랑 조작·초록 상태를 참고한다.

## 시나리오 / 권장 동작 / 예상 검증

| ID | 시나리오 | 기준 |
|---|---|---|
| T1 | 업데이트 | 한 번 탭, 일반 100ms/X 45ms, 길이 62%를 기본값으로 보존. |
| T2 | 실수 탭이 많음 | 한 번/두 번 탭 선택. 두 번은 350ms·가까운 위치 내에서만 한 번 실행. |
| T3 | 세기를 바꾸고 싶음 | 60–160% 조절. 100%는 기존 값. 앱별 실제 관성 거리는 다름을 안내. |
| T4 | 짧게 쓸고 싶음 | 제스처 길이를 대상 영역의 40–75%로 조절. 반복 자동 스크롤을 추가하지 않음. |
| T5 | 잠시 끄기 | 앱 안 일시정지로 상단 overlay 제거. 시스템 접근성 권한과 별개 상태로 표시. |
| T6 | 취소/기본값/재실행 | 취소는 미저장, 기본값은 확인 후 조절값만 복원, 재실행에도 저장값 유지. |
| T7 | 알림창/사용자 개입 | 아래로 끌기는 그대로 알림창, 두 번 탭 대기 초기화, 예약된 반복 플릭 없음. |
| T8 | 스크롤 대상 없음 | 전체 화면 임의 제스처 대신 실행하지 않음. 자기 설정 앱과 시스템 UI는 제외. |

길이·속도는 한 번의 합성 스와이프 입력값이지 실제 목록 이동 거리·iOS 애니메이션 시간이 아니다.
내 판단: 숫자를 자유롭게 열어도 위험한 조합은 막아야 한다. 제어권과 반복 실패 방지를 함께 유지한다.

## 의존성과 검증

순수 범위 모델·두 번 탭 판정 → prefs → 서비스 소비와 변경 수신 → UI → 순수/실기기 시험.
시나리오 리뷰, 순수 경계·오래된 탭·알림 드래그 취소 테스트, 폰 저장·취소·재실행·권한 유지와
통제된 스크롤 화면 시험으로 세 번 검증한다. 임의의 X 게시물·동영상을 클릭하거나 계정 상태를
바꾸는 시험은 하지 않는다. 발견한 차이는 결과 문서와 이 설계에 추가한다.

## 구현 중 발견과 설계 보완 — 2026-09-08

1. 기존 코드는 스크롤 대상을 못 찾을 때에도 화면 전체를 기준으로 플릭할 수 있었다.
   T8에 맞게 null 대상이면 중단한다. 대상이 없는 화면의 동작 범위를 넓히지 않는 것이 우선이다.
2. 두 번 탭을 기다리다 길게 누르거나 여러 손가락으로 만진 뒤 이전 탭이 남으면 의도하지 않은
   실행이 생긴다. 유효하지 않은 UP·POINTER_DOWN·OUTSIDE·CANCEL에서 대기를 초기화한다.
3. 시스템 접근성 허용과 앱 내부 일시정지는 다르다. 앱에서 꺼도 권한 자체를 해제하지 않으며,
   실제 상단 터치 영역을 제거한다. 다시 켜면 같은 권한으로 복원한다.
4. 세기와 길이는 안전 범위 내의 단일 입력만 조절한다. 종료 후 재가속하는 반복 동작은 추가하지 않는다.
5. 업데이트와 UI 자동화 시험 뒤 권한 목록에 있어도 서비스가 연결 대기에 머무는 경우를 실측했다.
   설치 검증은 권한 문자열만 보고 끝내지 않는다. Bound services, 실제 상단 overlay, 실제 한 번 탭
   동작을 함께 확인한다. 앱이 스스로 권한을 허용하거나 재연결을 강제하는 코드는 넣지 않는다.
