# APK 배포와 업데이트

앱 소스의 커밋과 APK 배포는 별개입니다. 소스를 수정하거나 커밋했다고 자동 배포하지 않습니다.
명시적으로 배포를 결정한 변경만 모아 Release로 제공합니다.

## 서명

각 앱은 고정된 배포용 키로 서명합니다. 키와 비밀번호는 저장소·APK·Release·빌드 로그에 넣지 않습니다.
키를 잃으면 같은 서명으로 업데이트할 수 없으므로 별도 안전한 백업이 필요합니다.
키 교체가 필요해지면 Android의 서명 계승과 OS 호환성을 검토한 뒤 별도 이관을 안내합니다.
갑자기 새 키로 덮어쓰거나 사용자의 앱을 삭제하지 않습니다.

`build.sh`의 테스트용 키는 공식 배포용 키가 아닙니다.
기존 개인 테스트 설치본과 공식 APK의 서명이 다르면 덮어쓰기가 거절되는 것이 정상입니다.

## 1.1.1 배포할 소스를 고정하기

앱별 versionCode를 이전 배포보다 올리고 버전 이름을 정합니다.
관련 테스트와 공개 파일 검사를 실행한 뒤 배포 커밋을 고정합니다.
빌드는 해당 커밋의 깨끗한 소스에서 시작하고 출처 SHA를 기록합니다.
개인 작업 폴더를 통째로 압축하면 비공개 자료가 섞일 수 있어 사용하지 않습니다.

## 1.1.2 빌드와 서명하기

JDK 17, SDK Platform 36, Build Tools 36.0.0을 사용합니다. 앱의 build.sh를 먼저 실행합니다.
APK_RELEASE_KEYSTORE, APK_RELEASE_ALIAS, APK_RELEASE_PASSWORD를 안전한 로컬 환경에 설정한 뒤:

~~~sh
sh tools/sign-release.sh tap-to-top /output/tap-to-top-VERSION.apk
~~~

출력 디렉터리는 미리 준비합니다. 앱 이름은 `tap-to-top`, `holiday-sleep`, `airpods-glance` 중 하나입니다.
이 도구는 키를 만들거나 APK를 업로드하지 않으며, 같은 출력 파일이 있으면 중단합니다.
키의 공개 인증서 지문과 APK의 SHA-256은 배포 manifest에 기록합니다.
비밀번호를 쉘 기록이나 명령 인수에 직접 붙여 쓰지 않습니다.

## 1.1.3 설치 경로와 호환성 확인하기

서명, 최소 Android 버전, debuggable 해제, 권한과 라이선스를 검사합니다.
새 설치와 같은 서명의 재설치를 확인하되, 같은 APK 재설치와 버전이 올라가는 업데이트 시험은
구분합니다. 기존 사용자 설정을 지워서 통과시키지 않습니다.

첫 배포 준비에서 공휴일 앱의 minSdk 26과 API 35부터 존재하는 AutomaticZenRule.Builder 사용이
맞지 않음을 발견했습니다. aapt2와 d8의 최소 버전을 35로 정정했습니다.
에어팟 앱은 설치 조건이 API 31이지만 AAP 수신 경로는 API 37 이상이라는 제한을 설치 안내에 적었습니다.

## 1.1.4 Release에 올리기

검증한 APK 세 개, 해당 커밋의 대응 소스, 해시 목록과 공개용 빌드 manifest를 첨부합니다.
GPL 소스와 빌드 스크립트, 제3자 라이선스가 대응 소스에 포함돼 있어야 합니다.
키·개인 설정·연구 로그·개인정보가 있는 테스트 화면은 첨부하지 않습니다.
확인한 환경과 남은 시험을 적고, 올린 APK를 다시 내려받아 해시와 파일 목록을 확인합니다.

## 아직 확인하지 않은 것

여러 Galaxy 기기에서 다운로드·설치·권한 허용을 처음부터 따라 하는 시험과
별도 기기에서의 키 복구 시험은 남아 있습니다.
모든 기기에서의 동작을 보장하지 않습니다.

## v0.0.4 소음 제어·위젯 업데이트 확인 — 2026-09-16

별도 Android 15 가상 기기에서 세 앱의 0.0.3 공식 APK를 0.0.4 후보로 삭제 없이 업데이트하고
시험용 카드·시간·스크롤 설정 유지를 확인했습니다. 새 설치·첫 실행·같은 APK 재설치도 각각 통과했습니다.
기존 공식 인증서와 요청 권한은 같고, 배포 번호는 에어팟 6·공휴일 9·맨 위로 톡 12입니다.

기능 변경은 에어팟 소음 제어·전용 위젯·전환 순서 편집기입니다. 다른 두 앱은 버전만 맞췄습니다.
이 배포에서 개인 폰 설치본을 바꾸지 않았습니다. 위젯의 실제 소음 전환·음악 유지·삼성 잠금 제어 등
남은 확인은 [호환성 기록](../compatibility/#2026년-9월-16일--소음-제어-위젯과-설정-화면)을 따릅니다.

## v0.0.3 잠금화면 위젯 업데이트 확인 — 2026-09-14

세 앱을 기존 공식 0.0.2에서 0.0.3 후보로 삭제 없이 업데이트해 시험용 설정이 남는 것을 확인했습니다.
별도의 Android 15 가상 기기에서 새 설치·첫 실행·동일 APK 재설치도 확인했습니다.
배포 번호는 에어팟 5, 공휴일 8, 맨 위로 톡 11이며 기존 공식 서명과 요청 권한을 유지합니다.

기능 변경은 에어팟의 잠금화면 위젯입니다. 공휴일 수면 연장과 맨 위로 톡은 버전을 맞춰 재빌드했습니다.
실제 삼성 잠금화면의 표시·탭 사용 결과와 다른 기종의 미검증 범위는
[위젯 설계](../apps/airpods-glance/docs/design/018-lock-screen-widgets.md)에 따로 적었습니다.
이번 배포 과정에서 사용자 폰의 개인 테스트 설치본은 바꾸지 않았습니다.

## v0.0.2 아이콘 업데이트 확인 — 2026-09-14

후속 v0.0.2는 아이콘 변경입니다. 0.0.1에서 인증서가 같은 새 APK로 업데이트해
시험용 설정 유지를 다시 확인했습니다. 배포 번호는 에어팟 4, 공휴일 7, 맨 위로 톡 10입니다.
Galaxy Z Fold8의 개인 테스트 설치본도 기존 개인 서명으로 삭제 없이 업데이트했습니다.
공식 배포 키와 개인 테스트 키를 섞어 쓰지 않았습니다.

## v0.0.1 업데이트 확인 — 2026-09-14

세 앱 모두 이전 공개 APK와 인증서가 같고 내부 versionCode가 더 높은지 검사했습니다.
별도의 Android 15 가상 기기에 이전 공식 APK를 설치한 뒤 새 APK로 업데이트해,
시험용으로 넣은 스크롤·시간·카드 설정이 남는 것을 확인했습니다. 앱을 삭제해서 통과시킨 시험이 아닙니다.
이 확인이 실제 Galaxy의 모든 권한·위젯·백그라운드 일정 보존을 보장하는 것은 아닙니다.

## 외부 배포 정책 확인 — 2026-09-10

[Android 공식 안내](https://developer.android.com/developer-verification)는 2026년 9월 30일
브라질·인도네시아·싱가포르·태국의 참여 앱 스토어에 개발자 확인 기한을 안내하며,
2027년 이후 적용을 확대할 예정이라고 설명합니다. 미확인 앱을 설치하는 고급 사용자 경로도 별도로 안내합니다.
이번 GitHub APK 제공을 개발자 확인·Play 심사 완료로 표현하지 않습니다.
지역별 적용과 실제 설치 제한은 배포를 갱신할 때 다시 확인합니다.
