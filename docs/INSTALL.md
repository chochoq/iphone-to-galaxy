# 폰에서 설치하기

PC, USB 연결, 개발자 옵션이나 루팅 없이 설치할 수 있습니다.
원하는 앱만 설치하면 됩니다.

## 1. APK 받기

[첫 미리보기 배포](https://github.com/chochoq/iphone-to-galaxy/releases/tag/v0.1.0-preview.1)에서
원하는 앱의 `.apk` 파일을 받습니다. `Source code`는 개발용 소스이며 설치 파일이 아닙니다.

| 파일 이름의 시작 | 앱 | APK 설치 조건 |
| --- | --- | --- |
| `tap-to-top` | 맨 위로 톡 | Android 12 이상 |
| `holiday-sleep` | 공휴일 수면 연장 | Android 15 이상 |
| `airpods-glance` | 에어팟 한눈에 | Android 12 이상. 아래 기능 제한 참고 |

설치 가능 여부가 모든 기능의 동작을 보장하지는 않습니다.
에어팟 앱의 연결 후 AAP 배터리 수신 경로는 현재 코드에서 Android 17 이상에만 켜집니다.
이전 버전의 BLE 잔량 수신과 다른 기종에서의 동작은 검증하지 않았습니다.
기존 기능 시험은 Galaxy Z Fold8 / Android 17 / One UI 9.0 기준입니다.

## 2. 설치하기

1. 받은 APK를 엽니다.
2. 설치 출처 허용을 요구하면 사용한 브라우저나 파일 앱에만 허용합니다.
3. 설치가 끝나면 앱을 엽니다.
4. 임시로 허용한 ‘출처를 알 수 없는 앱 설치’는 다시 꺼도 됩니다.

삼성의 ‘보안 위험 자동 차단’이 설치를 막는다면 표시된 이유를 먼저 확인합니다.
외부 APK 설치를 위해 해당 설정을 일시적으로 바꿔야 할 수 있습니다. 변경을 원치 않으면 설치를
중단해도 됩니다. Play 프로텍트 등 다른 보안 기능까지 모두 끄지 말고, 바꾼 설정은 설치 뒤 되돌립니다.
회사 관리 폰에서 차단되면 우회하지 말고 담당자에게 확인합니다.

## 3. 앱별 권한 켜기

| 앱 | 허용할 항목 | 처음에 할 일 |
| --- | --- | --- |
| 맨 위로 톡 | 접근성 → 설치된 앱 → 맨 위로 톡 | 앱에서 접근성 설정 열기 |
| 에어팟 한눈에 | 근처 기기, 알림. 큰 카드는 ‘다른 앱 위에 표시’도 필요 | Galaxy에서 AirPods 페어링 후 앱에서 기기 선택·감시 켜기 |
| 공휴일 수면 연장 | 캘린더 읽기, 방해 금지 접근, 알람 및 리마인더 | 대한민국 공휴일 캘린더 동기화 확인 후 시간 설정·자동 연장 켜기 |

맨 위로 톡에서 **‘제한된 설정’** 안내가 나오면 설정 → 애플리케이션 → 맨 위로 톡 → 메뉴에서
‘제한된 설정 허용’ 항목을 확인합니다. 설치 출처를 확인한 앱에만 허용하고 접근성 설정으로 돌아갑니다.
메뉴 이름이나 제공 여부는 OS와 설치 경로에 따라 다릅니다.

공휴일 앱은 방해 금지 시간을 연장합니다. 기상 알람을 만들거나 늦추지 않습니다.
평소 수면 일정과 시계 앱의 ‘공휴일에는 알람 끄기’는 별도로 설정합니다.
[공휴일 수면 설정 자세히 보기](../recipes/holiday-extension.md)

## 업데이트와 삭제

공식 배포본끼리는 같은 서명과 더 높은 버전으로 업데이트합니다.
직접 빌드한 APK나 이전 개인 테스트 APK는 서명이 달라 덮어쓰기가 안 될 수 있습니다.
이때 바로 삭제하지 말고 설치된 앱의 출처와 버전을 먼저 확인하세요.
삭제하면 앱 설정이 지워지고 권한을 다시 켜야 할 수 있습니다.

공휴일 앱을 삭제할 때는 먼저 앱에서 자동 연장을 끄고 방해 금지 규칙도 꺼졌는지 확인합니다.
각 앱의 자세한 삭제 방법과 권한 설명은 [앱 문서](../apps/)에 있습니다.

## 확인 범위

빌드·서명·권한 검사와 별도의 Android 15 가상 기기에서 설치·첫 실행을 확인했습니다.
가상 기기의 ADB 설치는 Galaxy에서 파일을 눌러 설치하는 것과 다릅니다.
새 사용자 Galaxy에서 다운로드부터 권한 허용까지 따라 하는 시험은 아직 남아 있습니다.

설치 제한은 지역·기기 정책에 따라서도 달라질 수 있습니다.
[Android 제한된 설정 안내](https://support.google.com/android/answer/12623953?hl=ko) ·
[Android 개발자 확인 제도](https://developer.android.com/developer-verification)
