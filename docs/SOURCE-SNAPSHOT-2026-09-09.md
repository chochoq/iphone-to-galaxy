# 2026-09-09 소스 반영 범위

사용자가 요청한 UI·설정·아이콘 변경만 선별했습니다. 개발 기기의 앱 데이터나 서명 키를
옮긴 것이 아닙니다. APK 파일·새 버전 태그·릴리스도 이 묶음에 포함하지 않습니다.

## 포함한 변경

| 앱 | 개발 버전 | 변경 |
|---|---|---|
| 공휴일 수면 연장 | 1.2.2-dev | 시작·종료 시간 저장과 취소, 기존 상태 유지, 화면과 아이콘 |
| 맨 위로 톡 | 1.5.0-dev | 탭 횟수·스크롤 세기·길이, 일시정지와 기본값 복원, 화면과 아이콘 |
| 에어팟 한눈에 | 1.1.0-dev | 카드 닫기 방식·배터리 알림 기준, 화면과 아이콘 |

공개본의 공통 SDK 탐색·개발용 서명 경로와 제3자 라이선스 전문은 유지했습니다.
기존 제품 회전 영상과 공개용으로 편집한 GIF도 그대로입니다. 새 런처 아이콘은 별도로
생성한 그림이며, 제작 기록과 출처 구분을 함께 넣었습니다.

앱 소스의 `dev` 표시는 개발 설치본을 구분하기 위한 이름입니다. 정식 배포 버전이나
다른 기기 지원을 약속하는 표시는 아닙니다.

## 이번 공개본에서 다시 검사한 것

- 공휴일 수면 연장: 시간 모델 2,419,550회, 저장 대역 10회, 예약 대역 18회 검사 통과.
- 맨 위로 톡: 설정·탭 판정 7,395회 검사 통과.
- 에어팟 한눈에: 핵심 로직 263,039회 검사 통과.
- 세 앱 모두 공개본의 빌드 도구로 APK 생성과 서명 검증 통과.
- 에어팟 APK의 권한 정책과 포함된 제3자 라이선스 전문 검사 통과.
- 공개본 개인정보·금지 파일·라이선스 검사와 변경 문서의 상대 링크 검사 통과.
- 세 앱의 제품 Java 소스와 XML이 정본과 일치함을 확인했고 연구 도구는 제외했습니다.

숫자는 입력 조합에 대한 assertion 횟수입니다. 실제 사용자 시나리오나 Bluetooth 연결을
그만큼 시험했다는 뜻이 아닙니다. 이번에는 휴대폰에 다시 설치하거나 기기 설정을 바꾸지 않았습니다.

실기기 화면·설정 검증은 각 앱의 9월 8일 결과 문서를 따릅니다. 새 버전의 모든 공휴일 경계,
전화·알람, 모든 타사 피드와 AirPods 음악 연결을 다시 확인한 것은 아닙니다.

## 포함하지 않은 것

진행 중인 케이스 소리 연구와 별도 진단 앱·기록 분석기는 이 묶음에서 제외했습니다.
원시 Bluetooth 기록, 기기 화면 원본, 개인 이름·주소·위치, 계정 정보, 서명 키도 넣지 않았습니다.
소스의 로컬 커밋과 원격 업로드·APK 배포는 별도 단계입니다.
