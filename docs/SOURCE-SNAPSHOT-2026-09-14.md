# 2026-09-14 소스 반영 범위

후속: 이 문서는 소스를 먼저 선별해 커밋한 시점의 기록입니다.
이후 사용자의 APK 갱신 요청으로 같은 날 v0.0.1에 반영했습니다. [현재 다운로드와 설치](INSTALL.md)

9월 11~14일 수정한 설정 화면과 홈 위젯을 모았습니다. 소스 커밋이며 APK 출시가 아닙니다.
기존 다운로드 링크와 배포 버전은 바꾸지 않았습니다.

## 포함한 것

- 세 앱의 공통 설정 화면, 시간·숫자 편집, 초안·취소·저장 상태 처리.
- 취소·저장 주변 여백과 초기화 버튼 사이 간격 수정.
- 에어팟의 원형 홈 위젯: 3×1·2×1·1×1 선택, 실제 공간에 맞춘 원·글씨 크기 계산.
- 1×1의 부품별 표시와 위젯별 선택 저장 구현. 실제 홈 탭 전환은 아직 미검증.
- 공통 UI 의존 소스, 빌드 경로, 순수 모델 테스트와 CI 연결, 격리 Android 위젯 검사 코드.

서명 키, 개인 기기 캡처·로그·설정, 참고용 디자인 파일, 케이스 소리 연구와 진단 도구는 제외했습니다.
기존 공개본의 라이선스 전문·고지, 개인정보 메타데이터를 제거한 제품 이미지도 보존했습니다.

## 선별한 소스에서 다시 검사한 것

공개 가능한 파일만 별도 폴더에 복사한 뒤 시험했습니다. 개발 폴더의 APK를 결과물로 대신하지 않았습니다.

| --- | --- |
| 공통 입력 모델 / 저장 작업 | 4,816 / 45 통과 |
| 맨 위로 톡 설정·탭 판정 | 7,395 통과 |
| 수면 시간 모델 / 저장 대역 / 예약 대역 | 2,419,550 / 10 / 18 통과 |

숫자는 조건 조합에 대한 검사 횟수입니다. 사람이나 Bluetooth 연결을 그만큼 시험했다는 뜻은 아닙니다.
새로 만든 개발용 APK를 사용자 휴대폰에 설치하거나 기존 배포 키로 서명하지 않았습니다.

## 앞서 확인한 실물과 남은 시험

9월 11일 설정 화면·버튼 간격을 수정해 세 앱을 Fold8에 업데이트했습니다.
9월 14일 위젯은 Fold8 커버 화면의 삼성 추가창에서 3×1·2×1·1×1을 확인했고 홈에도 놓아 봤습니다.
당시 설정은 Android 17·One UI 9.0·글씨 80%였습니다.

별도 Android 네이티브 위젯 시험은 4,267개 사례 / 42,731개 검사를 통과했습니다.
코드로 생성·재적용한 레이아웃 결과이며, 실제 홈의 클릭 전달 시험과는 다릅니다.
검사 소스는 `shared/android-ui/tests/widget/`에 포함했습니다.

1×1의 홈 탭 전환과 재부팅 후 선택 유지, 펼친 폴드 전환, 다른 런처와 TalkBack 음성 탐색은
확인이 남아 있습니다. 잠금화면 시계 아래에 위젯을 넣는 기능도 이번 구현에 포함하지 않았습니다.
새 배터리 수신·음악·실제 공휴일 경계·전화·알람·타사 앱 스크롤을 모두 재검증한 것은 아닙니다.
