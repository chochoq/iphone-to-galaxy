실제 화면 그대로 남겼습니다. 숫자 편집에 보이는 값은 테스트 입력이며 사용자의 설정이 아닙니다.
화면 동작과 표시를 보여 주는 사진이지, 실제 Bluetooth 잔량 수신이나 공휴일 자동 실행 시험은 아닙니다.

[3×1](widget-wide.png) · [2×1](widget-small.png) · [1×1](widget-single.png)

## 잠금화면 위젯

[`airpods-lock-widget-demo.gif`](airpods-lock-widget-demo.gif)는 2026년 9월 14일 제공된
Galaxy Z Fold8 실기기 촬영 영상을 편집한 GIF입니다. Android 17·One UI 9.0에서
잠금화면 위젯을 직접 눌러 왼쪽 → 오른쪽 → 케이스 → 왼쪽으로 바꾸는 모습을 담았습니다.

- 시계·위젯이 있는 화면 안쪽만 잘라 책상·휴대폰 테두리·상태 표시줄을 제외했습니다.
- 원본의 2.15~5.95초 구간, 한 차례 순환하는 장면을 사용했습니다. 순서와 재생 속도는 바꾸지 않았습니다.
- 504×450, 초당 15프레임의 약 3.8초 반복 GIF입니다. 웹에서 색이 맞도록 sRGB로 변환했습니다.
- 소리·위치·기기 정보 등 원본 촬영 메타데이터는 넣지 않았습니다.

움직임이나 화면 내용을 합성한 영상이 아닙니다. 실제 손가락 조작과 화면 반응을 그대로 담았습니다.
숫자는 앱이 마지막으로 수신한 잔량이며, 탭할 때마다 새 잔량을 측정하는 장면은 아닙니다.
원본 MOV와 편집 중간 파일은 공개하지 않았습니다. 촬영·편집: chochoq.
