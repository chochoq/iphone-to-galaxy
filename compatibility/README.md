| 실제 시험 환경 | Galaxy Z Fold8 (SM-F971N) | Android 17, One UI 9.0 | 현재 직접 확인한 유일한 Galaxy |

## 기록 방법

- ‘지원’이라는 말은 여러 환경에서 충분히 확인했을 때만 사용합니다. 지금은 ‘직접 확인’이라고 씁니다.
- Fold는 커버 화면과 펼친 화면의 결과를 따로 기록합니다.
- 화면 확대, 글자 크기, 탐색 방식과 밝은·어두운 테마가 결과에 영향을 주면 함께 적습니다.
- 운영체제가 업데이트되어도 예전 결과를 지우지 않고 날짜가 있는 새 기록을 추가합니다.

## 2026년 9월 7일 결과

| 기능 | 확인한 내용 | 화면 상태 | 판단 |
|---|---|---|---|
| 맨 위로 톡 1.4.1 | X, YouTube, Chrome과 Samsung 설정에서 위로 한 번 이동하고 중간에 멈추는 동작 | 당시 활성 화면만 기록 | 커버·펼친 화면을 나눠 다시 시험해야 함 |
| Holiday Sleep | 한국 공휴일 인식, 전용 방해 금지 규칙과 다음 실행 예약 | 화면과 관계없는 백그라운드 동작 | 한 기기에서 확인 |
| AirPods Glance | 연결, 음악 유지, 좌우·케이스 배터리, 4×1 위젯, 지속 연결 화면과 회전 영상 | 당시 활성 화면만 기록 | 실험용이며 Fold 상태별 시험이 더 필요함 |
| 회의·수면·생활 루틴 | 실제 사용 구성 | 메뉴 설정을 내보내지 않음 | 공개용 재현 절차를 보완해야 함 |
| One Hand Operation+ | 양쪽 손잡이를 사용하고 오른쪽을 주로 쓰는 구성 | 방향별 배치는 다시 확인해야 함 | 설정 재확인 필요 |

화면 상태가 비어 있는 항목은 실패했다는 뜻이 아니라 당시 기록하지 못했다는 뜻입니다. 다시
시험할 때는 기존 결과를 덮어쓰지 않고 날짜와 화면 상태가 있는 행을 추가합니다.

## 2026년 9월 14일 추가 확인

- Fold8 커버 화면에서 에어팟 3×1·2×1·1×1 위젯의 추가창과 홈 표시를 확인했습니다.
- 별도 Android 15 가상 기기에서 세 앱의 이전 공식 APK → v0.0.1 업데이트와 시험용 설정 유지를 확인했습니다.
- v0.0.1 설정 화면에서 저장·취소·잘못된 값 차단·화면 재생성 등 32개 조작 검사를 통과했습니다.
- README의 설정 사진은 이 가상 기기에서 캡처했습니다. 실제 Bluetooth 수신이나 공휴일 자동 실행의 증거로 쓰지 않습니다.

1×1의 삼성 홈 탭 전환·재부팅 후 선택 유지, 다른 런처·펼친 폴드와 TalkBack 음성 탐색은
확인이 남아 있습니다. 잠금화면 시계 아래 위젯은 구현하지 않았습니다.
