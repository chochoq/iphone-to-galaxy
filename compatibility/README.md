## 기록 방법

- ‘지원’이라는 말은 여러 환경에서 충분히 확인했을 때만 사용합니다. 지금은 ‘직접 확인’이라고 씁니다.
- Fold는 커버 화면과 펼친 화면의 결과를 따로 기록합니다.
- 화면 확대, 글자 크기, 탐색 방식과 밝은·어두운 테마가 결과에 영향을 주면 함께 적습니다.
- 운영체제가 업데이트되어도 예전 결과를 지우지 않고 날짜가 있는 새 기록을 추가합니다.

시험할 때는 기존 결과를 덮어쓰지 않고 날짜와 화면 상태가 있는 행을 추가합니다.
