# 어디에서 확인했나요?

## 기준 환경

마지막으로 사용한 **iPhone 14 Pro · iOS 26.6.1**이 익숙한 사용법의 기준입니다.

실제 시험 환경은 **Galaxy Z Fold8 (SM-F971N) · Android 17 · One UI 9.0**입니다.
직접 확인한 Galaxy는 이 한 대입니다.

아래는 2026년 9월 17일까지 확인한 범위입니다.
한 기기에서 작동한 결과가 다른 Galaxy·OS·화면 배치에서도 작동한다는 뜻은 아닙니다.

## 실기기에서 확인한 것

### 맨 위로 톡

0.0.5의 새 방식은 Fold8 커버 화면에서 확인했습니다.

| 화면 | 확인한 것 | 남은 한계 |
|---|---|---|
| 인스타 446.0.0.49.77 홈 | 깊은 피드에서 처음 도착, 이동 중 드래그로 중단 | 프로필·릴스·댓글·DM 전체는 미확인 |
| YouTube 21.37.42 홈 | 첫 항목·상단 메뉴 복귀, 이동 중 중단 | 검색·구독·Shorts 전체는 미확인 |
| X 12.25.2-prod.01 추천·팔로우 중 홈 | 처음 도착, 준비 단계에서 취소, 이미 상단이면 재선택 안 함 | X 자체 이동 도중 가로채기 미확인, 새 글 반영 가능성 |

기존 한 번 쓸어 올리기는 X·YouTube·Chrome·Samsung 설정에서 확인했습니다.
Chrome의 새 목적지 이동을 확인한 것은 아닙니다. 펼친 화면 전체 회귀와 다른 기기 시험도 남아 있습니다.
앱 업데이트로 화면 구조가 바뀌면 동작이 달라질 수 있습니다.

### 공휴일 수면 연장

한국 공휴일 인식, 전용 방해 금지 규칙, 다음 예약과 시간 설정 화면을 확인했습니다.
다른 캘린더 환경과 One UI의 규칙 조합은 확인하지 않았습니다.

### AirPods 배터리와 연결 카드

연결·음악 유지·좌우와 케이스 잔량·회전 카드를 확인했습니다.
다른 AirPods·OS 시험과 현재 버전의 방해 금지 중 새 연결 재시험은 남아 있습니다.

### 홈 배터리 위젯

커버 화면에서 3×1·2×1·1×1의 추가창과 홈 표시를 확인했습니다.
1×1 탭 전환·재부팅 후 선택 유지, 펼친 화면·다른 런처는 확인이 남았습니다.

### 잠금 배터리 위젯

목록·표시를 확인했고 사용자가 실제 부품 전환을 확인했습니다.
AOD·밝은 배경 대비·실제 재부팅 후 복원은 확인하지 않았습니다.

### 앱 안 소음 제어

노캔·적응형·주변음 전환과 기기 응답을 확인했고, 사용자는 음악 끊김이 없었다고 확인했습니다.
다른 휴대폰·AirPods 모델과 환경별 적응 효과는 검증하지 않았습니다.

### 소음 제어 위젯과 전환 순서 편집기

위젯 개발본의 홈 표시와 연결 없음 안내를 확인했습니다.
위젯으로 실제 모드를 바꾸는 동작·음악 유지·잠긴 화면 제어는 아직 확인하지 않았습니다.

새 한 목록 편집기는 Fold8에 설치하지 않았습니다. 가상 기기의 결과는 아래에 구분했습니다.
Fold8 화면·터치·TalkBack 음성 탐색 확인이 남아 있습니다.

회의·수면·생활 루틴은 한 기기에서 사용했지만 공개용 메뉴 절차를 모두 재현한 것은 아닙니다.
회의 녹음 시작 동작과 One Hand Operation+ 방향별 배치는 재확인이 필요합니다.

## 자동 검사와 별도 Android 환경

모델 검사는 입력 조합·수명·시간 경계를 검사합니다. 실제 Bluetooth나 런처 동작의 증거로 쓰지 않습니다.

Android 15 가상 기기에서는 세 앱의 설정 화면, 새 설치·재설치, 공식 APK 업데이트와 시험용 설정 유지를 검사했습니다.
0.0.4는 0.0.3 위에 삭제 없이 업데이트하는 경로를 확인했습니다.
0.0.5도 이전 공식 0.0.4에서 설정·UID·첫 설치 시각 유지와 동일 APK 재설치를 확인했습니다.
합성 설정으로 업데이트를 검사한 뒤, 별도 새 설치·첫 실행도 확인했습니다.
이 결과가 Galaxy의 모든 권한·백그라운드 일정·위젯 복원을 보장하지는 않습니다.

소음 제어 편집기는 36개 화면 조합과 실제 터치 정렬·저장·취소·화면 재생성을 검사했습니다.
RemoteViews 렌더와 클릭 전달 시험도 실제로 잠긴 Samsung 화면의 제어 시험과 구분합니다.
README의 설정·소음 선택 이미지는 [촬영·렌더 환경](../docs/images/README.md)에 표시했습니다.

맨 위로 톡은 별도 API 35 환경에서 실제 RecyclerView 1.4.0의 긴 목록·중첩 구조·사용자 개입과
웹·그리드·행 정보 누락의 한계를 검사했습니다. 일반 한 열 목록은 1,000번째 항목 부근에서도
처음에 도착했습니다. 그리드의 방향 오판과 기본 ListView의 항목 단위 이동을 재현해
새 공통 경로로 추가하지 않았습니다. [검사와 기술적 범위](../apps/tap-to-top/docs/DEVELOPMENT.md)

검사를 재현하려면 [기여 안내](../CONTRIBUTING.md)의 앱별 개발 문서를 참고하세요.
