# 회의 모드 — 수동 한 번, 종료 복원 한 번

## 현재 의도

`회의` 모드는 자동 조건이 아니라 사용자가 직접 시작한다. 시작 action은 Bluetooth 끄기와 Samsung
음성 녹음 앱 열기이며, 전화 정책은 기기 소유자가 선택한 차단 동작을 쓴다. 종료할 때 Bluetooth와
전화 상태를 원래대로 복원한다.

## 왜 녹음 시작을 임의로 누르지 않는가

앱 실행은 Samsung 루틴의 공식 action으로 가능하지만 녹음 버튼 누르기는 별개의 행위다. 좌표 기반
자동 탭은 Fold의 화면 상태·글자 크기·앱 업데이트에 따라 엉뚱한 곳을 누를 수 있고 광범위한 접근성
권한을 요구한다. 공식 `녹음 시작` action이 현재 기기에 노출되는지 확인되기 전에는 자동 시작을
완료로 표기하지 않는다.

## 부작용 시험

- Bluetooth off로 AirPods뿐 아니라 키보드·마우스도 끊어지는지 확인한다.
- 전화 차단이 발신자에게 어떤 안내를 주는지 별도 전화로 확인한다.
- 녹음 앱을 열었을 때 실제 입력이 휴대폰 마이크인지 짧게 녹음해 재생한다.
- 모드 종료 뒤 Bluetooth가 원래 상태로 복원되는지 확인한다.

현재 mapping의 메뉴별 export가 공개 staging에 없으므로 이 문서는 원칙과 시험표이며, 아직 타인의
기기에 그대로 적용하는 완성 recipe가 아니다.
