# 설정과 루틴 레시피

새 앱 없이 해결한 Galaxy 설정, Good Lock 구성과 모드·루틴을 기록합니다.

각 레시피에는 적용 전 상태, 정확한 메뉴 경로, 기대 결과, 부작용, 원상복구 방법과 실제 검증한
One UI 버전을 포함합니다.

| 레시피 | 해결 수준 | 공개 상태 |
|---|---|---|
| [수면 일정과 예외](sleep-schedule.md) | Samsung 모드 | 단일 기기 검증 기록 |
| [공휴일 수면 연장](holiday-extension.md) | Samsung 모드 + 직접 앱 | 단일 기기 검증 |
| [회의 모드](meeting-mode.md) | Samsung 모드·루틴 | 세부 mapping 재확인 필요 |
| [집·외출·배터리 루틴](home-away-battery.md) | Samsung 루틴 | 개인정보 제거 template |
| [한손 제스처](one-hand-gestures.md) | Good Lock | 세부 mapping 재확인 필요 |
| [재난문자 선택](emergency-alerts.md) | Galaxy 설정 | 사용자 안전 선택 |

One UI의 메뉴명은 기기·지역·업데이트에 따라 달라질 수 있습니다. 재확인이 끝나지 않은 레시피는
그 사실을 숨기지 않으며, 존재하지 않는 메뉴 경로를 추측해 적지 않습니다.
