# 집·외출·저전력 자동화 template

실제 주소, 지도 좌표와 Wi-Fi 이름은 공개하지 않는다. 아래 placeholder를 자기 기기에서 선택한다.

## 집 도착

- 조건: `<내 집>` 위치 진입 또는 `<신뢰 Wi-Fi>` 범위/연결
- action: Wi-Fi 사용과 신뢰 네트워크 연결에 필요한 설정
- 종료: 집을 떠났을 때 이전 Wi-Fi 상태로 복원

위치만 조건으로 쓰면 GPS 판정 지연이, Wi-Fi 연결만 조건으로 쓰면 Wi-Fi가 꺼진 상태에서 시작하지
못하는 순환 의존이 생길 수 있다. 한 조건을 먼저 실제로 시험한 뒤 필요할 때만 보조 조건을 추가한다.

## 외출

- 조건: `<내 집>` 이탈
- action: 임의의 공개 Wi-Fi 자동 연결을 줄이도록 Wi-Fi 동작 조정
- 종료: 귀가 루틴과 충돌하지 않게 한 쪽만 최종 상태를 소유

Wi-Fi 전체를 끄면 위치 정확도, nearby 기기 탐색과 다른 루틴 조건에도 영향이 갈 수 있다. “알 수
없는 네트워크에 자동 연결하지 않기”라는 목표와 “Wi-Fi radio 끄기”를 같은 것으로 취급하지 않는다.

## 저전력

- 조건: `<내가 선택한 배터리 임계값>` 아래이며 충전 중이 아님
- action: 절전 모드
- 종료: 임계값 회복 또는 충전 시작 때 원래 설정 복원

Fold의 화면 주사율, background sync와 위치 판정이 제한될 수 있으므로 메신저·캘린더·루틴 지연을
시험한다. 공개본에서는 실제 사용 중인 임계값을 확인하기 전 숫자를 추측하지 않는다.

## 원상복구

세 루틴을 각각 비활성화한 뒤 Wi-Fi와 절전 모드를 수동으로 원하는 상태로 맞춘다. 장소와 SSID를
삭제할 때 다른 루틴이 같은 조건을 참조하는지 먼저 확인한다.
