# 집·외출·저전력 자동화 예시

실제 주소·좌표·Wi-Fi 이름 대신 예시를 사용했습니다. 장소·네트워크·배터리 기준은 자신의 기기에서 고릅니다.

별도 앱 없이 Samsung 모드·루틴을 사용합니다. 회의 모드와 달리 조건에 따라 자동으로 시작·종료합니다.
위치 조건은 위치 권한과 백그라운드 확인에 영향을 받습니다. 화면을 공유할 때에도 지도·주변 장소·계정을 가려 주세요.

## 집에 도착했을 때

- 시작 조건: `내 집`에 도착하거나 `신뢰하는 Wi-Fi`가 보이거나 연결됨
- 실행할 일: Wi-Fi를 켜고 신뢰하는 네트워크 사용
- 끝날 때: 이전 Wi-Fi 상태로 복원

위치만 조건으로 쓰면 도착 판단이 늦을 수 있습니다. 반대로 Wi-Fi 연결만 조건으로 쓰면 Wi-Fi가
꺼져 있을 때 루틴이 시작되지 않는 문제가 생길 수 있습니다. 조건 하나를 먼저 시험하고 꼭 필요할
때만 다른 조건을 보태는 편이 좋습니다.

## 집을 나섰을 때

- 시작 조건: `내 집`을 벗어남
- 실행할 일: 모르는 공개 Wi-Fi에 자동으로 연결되지 않도록 Wi-Fi 설정 조정
- 끝날 때: 귀가 루틴과 같은 설정을 동시에 바꾸지 않도록 한쪽에서만 복원

Wi-Fi를 완전히 끄면 위치 정확도와 근처 기기 검색, 다른 루틴에도 영향을 줄 수 있습니다. 모르는
네트워크에 자동으로 연결하지 않는 것과 Wi-Fi 자체를 끄는 것은 다릅니다.

## 배터리가 부족할 때

- 시작 조건: 배터리가 `내가 고른 기준`보다 낮고 충전 중이 아님
- 실행할 일: 절전 모드 켜기
- 끝날 때: 배터리가 기준보다 높아지거나 충전을 시작하면 이전 설정으로 복원

절전 모드는 Fold의 화면 주사율, 동기화와 위치 확인을 제한할 수 있습니다. 메신저와 캘린더 알림,
다른 루틴이 늦어지지 않는지 확인해야 합니다. 현재 사용 중인 기준값을 다시 확인하기 전에는 특정
숫자를 권장하지 않습니다.

되돌리려면 세 루틴을 각각 끄고 Wi-Fi와 절전 모드를 원하는 상태로 직접 맞춥니다. 장소나 Wi-Fi
조건을 지우기 전에 다른 루틴에서도 같은 조건을 쓰고 있지 않은지 확인합니다.
