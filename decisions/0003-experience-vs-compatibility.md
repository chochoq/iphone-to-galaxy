# ADR-0003 — iPhone 경험 기준과 Galaxy 호환 범위를 분리한다

- 상태: 채택
- 날짜: 2026-09-07

## 결정

iPhone 14 Pro / iOS 26.6.1은 사용자가 익숙한 행동의 출처다. Galaxy Z Fold8 `SM-F971N` /
Android 17 / One UI 9.0은 구현을 직접 시험한 범위다. 전자를 지원 범위로, 후자를 전체 Galaxy의
대표로 표현하지 않는다.

Fold의 cover/main 화면 기록이 없으면 성공으로 추정하지 않고 `화면 상태 미기록`으로 둔다. 다른
기기의 성공은 기존 행을 넓히지 않고 별도 날짜·환경 행으로 추가한다.
