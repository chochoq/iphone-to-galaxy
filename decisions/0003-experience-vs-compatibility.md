# ADR-0003: 익숙한 아이폰과 시험한 Galaxy를 구분

- 상태: 채택
- 날짜: 2026-09-07

iPhone 14 Pro와 iOS 26.6.1은 제가 익숙했던 동작의 출처입니다. Galaxy Z Fold8 SM-F971N,
Android 17과 One UI 9.0은 구현을 직접 시험한 환경입니다. 앞의 정보는 지원하는 iPhone 목록이
아니며, 뒤의 결과도 모든 Galaxy를 대표하지 않습니다.

Fold의 커버 화면과 펼친 화면을 나누어 기록하지 않은 시험은 성공으로 넓혀 해석하지 않고
‘화면 상태를 기록하지 않음’으로 표시합니다. 다른 기기에서 성공하더라도 기존 결과를 수정하지
않고 날짜와 환경이 있는 새 행을 추가합니다.
