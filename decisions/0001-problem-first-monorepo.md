# ADR-0001 — 문제 중심 단일 저장소로 시작한다

- 상태: 채택
- 날짜: 2026-09-07

## 맥락

작업 결과에는 세 앱뿐 아니라 Galaxy 설정, Good Lock과 Samsung 모드·루틴이 있다. 앱별 저장소는
코드 경계를 깔끔하게 만들지만 “아이폰에서 하던 이 행동을 어디서 해결하지?”라는 사용자의 입구를
분산시킨다.

## 결정

처음에는 한 `iphone-to-galaxy` 저장소에서 문제 문서가 설정·공식 도구·앱을 연결한다. 앱은
`apps/` 아래 독립 build 단위로 유지한다. 앱의 release cadence나 기여자가 크게 달라질 때 split을
재검토한다.

## 결과

공통 원칙·호환성·issue form을 한 곳에서 유지할 수 있다. 반면 repository가 길어질 수 있으므로
README는 문제 지도만 보여주고 세부 history는 각 앱의 index로 보낸다.
