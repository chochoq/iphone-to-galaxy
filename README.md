# iPhone to Galaxy

> **English:** A field guide by a long-time iPhone user rebuilding familiar habits on a
> Galaxy Z Fold8. Every solution starts with Samsung's own settings; custom apps come last.

아이폰 3GS부터 아이폰만 사용하다가 Galaxy Z Fold8으로 바꿨습니다. 사진과 연락처는 옮길 수
있었지만, 손에 밴 사용법까지 따라오지는 않았습니다. 상태 표시줄을 눌러 맨 위로 가는 동작도,
공휴일 아침에는 수면 모드를 늦게 끝내는 설정도 Galaxy에서는 다시 찾아야 했습니다.

이 저장소에는 그때부터 하나씩 해결해 온 과정을 기록합니다. 불편하다고 바로 앱을 만들지는
않았습니다. Galaxy 설정, Good Lock과 Samsung 앱, 이미 나와 있는 앱, 자동화와 ADB를 차례로
확인했습니다. 직접 만든 앱은 앞선 방법으로 원하는 동작을 만들 수 없을 때만 사용했습니다.

비슷한 앱이 이미 있다면 함께 소개합니다. 우리가 처음 만들었다거나 모든 Galaxy에서 더 잘
동작한다고 주장하지 않습니다. 실제로 시도했다가 실패한 방법과 생각을 바꾼 이유도 설계 문서에
남깁니다. 지금까지 확인한 기존 프로젝트는 [이 문서](docs/LANDSCAPE.md)에 정리했습니다.

## 이 기록의 기준

아이폰 쪽 경험은 제가 마지막으로 사용한 환경을 기준으로 합니다.

- iPhone 사용 시작: iPhone 3GS
- 마지막 기종: iPhone 14 Pro
- 마지막 운영체제: iOS 26.6.1

Galaxy 쪽 결과는 다음 환경에서 직접 확인했습니다.

- 기기: Samsung Galaxy Z Fold8 (`SM-F971N`)
- 운영체제: Android 17
- One UI: 9.0
- 지역과 언어: 대한민국, 한국어

지금까지 직접 사용해 본 Galaxy는 위에 적은 Fold8 한 대입니다.

다른 Galaxy나 다른 One UI에서는 메뉴 이름과 동작이 달라질 수 있습니다. Fold의 커버 화면과
펼친 화면에서도 버튼이나 글자의 배치가 달라질 수 있습니다. 기기별로 확인한 결과는
[호환성 표](compatibility/)에 기록합니다.

| 불편했던 점 | 사용한 방법 | 확인 상태 |

표에 적힌 ‘한 기기에서 확인’은 제가 쓰는 Fold8에 앱을 설치하고 해당 기능이 동작하는 것을
직접 확인했다는 뜻입니다. 다른 Galaxy에서도 똑같이 작동하는지는 아직 확인하지 못했습니다.

특히 에어팟 배터리를 읽는 기능은 휴대폰 기종이 달라지거나 Android를 업데이트하면 작동하지 않을
수 있어 ‘실험용’으로 표시했습니다. 사용하기 전에 [에어팟 앱의 작동 방식과 한계](problems/airpods-on-galaxy.md)를
확인해 주세요.

## 어디서 시작하면 되나요?

설정만 따라 할지, PC로 폰을 조작할지, 직접 만든 앱을 설치할지에 따라 준비가 다릅니다.

| 하고 싶은 일 | 필요한 준비 |
|---|---|
| Galaxy 설정·Good Lock 가이드 따라 하기 | 폰에서 해당 설정이나 공식 앱 열기. 개발자 옵션과 PC는 필요하지 않습니다. |
| PC에서 ADB로 설정 작업 돕기 | PC의 Android SDK Platform-Tools와 폰의 USB 디버깅·PC 연결 승인 |
| 직접 만든 앱 설치하기 | APK를 만들어 실기기에서 시험했습니다. 다운로드용 APK는 아직 공개하지 않아 현재는 PC에서 직접 빌드·설치해야 합니다. |

앱을 설치하지 않고 따라 할 수 있는 설정은 [`recipes/`](recipes/)에 있습니다. 수면 모드,
재난문자, 회의 모드, 집과 외출 루틴, One Hand Operation+ 설정부터 살펴볼 수 있습니다.

세 앱 모두 APK를 만들어 Galaxy에 설치하고 시험했습니다. 현재 GitHub에는 소스와 문서를 공개했고,
내려받아 설치하는 APK 파일은 아직 올리지 않았습니다.

직접 빌드하려면 [`apps/`](apps/)의 안내를 따라 Android SDK Platform 36, Build Tools 36.0.0과
JDK를 준비합니다. `./build.sh`는 각 개발자의 테스트용 키로 서명된 설치 가능한 APK를 만듭니다.
공식 배포용 서명·업데이트 체계는 아직 준비 중입니다.

### Galaxy와 PC를 USB로 연결하기

아래는 PC에서 ADB로 설치·설정·테스트할 때의 준비입니다. 루팅과 OEM 잠금 해제는 필요하지 않습니다.
USB 연결만 쓸 때는 무선 디버깅도 켤 필요가 없습니다.

1. 폰에서 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 일곱 번 누릅니다.
   잠금 비밀번호를 요청하면 입력합니다.
2. 설정 첫 화면으로 돌아가 **개발자 옵션 → USB 디버깅**을 켭니다.
3. PC에 [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)를
   준비합니다. 이 안의 `adb`가 PC에서 폰과 통신하는 도구입니다.
4. 데이터 전송이 가능한 USB 케이블로 연결하고 폰의 잠금을 풉니다.
5. PC에서 `adb devices`를 실행합니다. 폰에 **USB 디버깅을 허용하시겠습니까?**가 나타나면
   자신이 연결한 PC인지 확인한 뒤 허용합니다. ‘이 컴퓨터에서 항상 허용’은 신뢰하는 개인 PC에서만
   선택합니다. 파일 접근 허용 창과 USB 디버깅 승인은 서로 다릅니다.
6. 다시 `adb devices`를 실행해 기기 옆 상태가 `device`인지 확인합니다.
   `unauthorized`는 아직 폰에서 승인되지 않았다는 뜻입니다.

`adb` 명령을 찾지 못하거나 연결 승인이 나타나지 않으면
[PC 준비·연결 문제 해결](docs/GETTING-STARTED.md)을 확인해 주세요. 메뉴 이름은 One UI에 따라
달라질 수 있습니다.

### USB 디버깅 다음에는 어떤 권한을 열어야 하나요?

USB 디버깅은 PC 연결 권한입니다. 설치한 앱이 사용할 권한은 앱을 열어 별도로 허용합니다.
사용할 기능에 필요한 항목만 켭니다.

| 앱 | 폰에서 허용할 항목 | 사용하는 기능 |
|---|---|---|
| [맨 위로 톡](apps/tap-to-top/) | 접근성의 설치된 앱에서 서비스 활성화 | 스크롤 영역을 찾고 위로 움직이기 |
| [공휴일 수면 연장](apps/holiday-sleep/) | 캘린더 읽기, 방해 금지 접근, 알람 및 리마인더(정확한 알람) | 공휴일 확인과 정해진 시각의 방해 금지 조절 |
| [에어팟 한눈에](apps/airpods-glance/) | 근처 기기, 알림, 큰 카드 사용 시 다른 앱 위에 표시 | AirPods 상태 읽기와 알림·연결 카드 표시 |

저는 PC에서 AI와 함께 개발하며 USB로 폰을 연결해 시험했습니다. 이 가이드를 따라 하는 데 AI는
필수가 아닙니다. AI에게 작업을 맡기는 경우에도 PC에서 ADB 명령을 실행할 수 있는 환경이 필요하며,
폰에서 직접 승인해야 하는 화면도 있습니다.

설치와 설정을 마친 뒤에는 USB 디버깅을 끄고 케이블을 빼도 세 앱의 기능은 동작하도록 만들어져
있습니다. 연결했던 PC의 승인을 지우려면 개발자 옵션의 ‘USB 디버깅 승인 취소’를 사용합니다.
앱 권한을 해제하거나 앱을 삭제하는 방법은 각 앱의 README에 있습니다.

## 권한과 개인정보

앱에는 광고와 분석 도구를 넣지 않았고, 실행 중 서버와 통신하지 않습니다. AirPods Glance를
빌드할 때 공개 Maven 저장소에서 의존성 하나를 내려받는 과정은 앱이 실행 중 인터넷을 사용하는
것과 다릅니다. 앱마다 요청하는 권한, 저장하는 정보와 삭제 방법을 README에 적었습니다.

공개할 소스에서는 집과 회사 위치, Bluetooth 주소, 개인 기기 이름, 로그, 서명 키와 화면 녹화를
제외했습니다. 자세한 기준은 [보안과 개인정보](SECURITY.md)에서 확인할 수 있습니다.

Apple이나 Samsung이 만들거나 승인한 프로젝트는 아닙니다. iPhone, AirPods, Galaxy와 One UI라는
이름은 비교한 경험과 시험 환경을 설명하기 위해 사용합니다.
